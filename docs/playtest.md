# 0.1.3 实机验收清单（直接操作与建造提示待验证）

0.1.1已在用户实机选中门时触发侧栏空引用；日志IL_011e定位为inactive父级按钮查找，0.1.2修复后需复测。当前57项逻辑回归和23项原生托管检查通过；素材检查单独报告，不计入行为用例。以下需要Unity和SimDLL。每项记录游戏版本、存档、预期/实际、截图/日志、总质量/病菌/能量；失败项阻止正式发布。

1. **Sim原子性门槛**：气/液同种、真空、异种微量、目标突然建砖/开普通门/接泵或排气口，确认EmitMass失败时质量完整返回账本且不覆盖他物；两个不同元素同时争真空。核对源/目标/缓存/恢复库存总和与病菌。
2. **保存门槛**：在取料已发/回调未到、投递已发/回调未到、回调刚完成时手动/自动保存和读档，暂停时保存，确认零时间屏障能结清且不重放；观察失败保存UI恢复。真存档往返总账必须一致。
3. **门导航门槛**：普通/仿生默认及个体单向权限；两朝向；通行进入第一格/第二格时手动或红线锁门，已有者安全退出，新者拒绝；暂停筛分不影响通行；中断、改道、倒地、死亡、连续两门和梯子移除。机器人/漫游车V1拒绝，野生动物不自行穿越。
4. **隔离/材质**：开闭动画持续气液隔离；上方地板支撑、落沙/碎块、房间边界、热传导、压力免疫不阻止周围正常受压；熔化/强制销毁时缓存由世界恢复，无空投物质。
5. **缓存**：H2缓存0.2kg时源侧变水；目标变水但源仍H2，缓存只填至0.5kg；两侧水停止耗电；在途空缓存仍锁H2；缓存清空后下一周期才切液体，240W/2kg规则正确。
6. **配置与拆除**：有库存切模式/方向/删白名单/降上限，旧路径排空；暂停、取消、无出口、无电力；拆除取消、原优先级与读档、已有旅客退出，实际施工和完成不误删库存。
7. **电路**：从砖和门任一占用格接线，暂停节点可供其他单元；相邻、拆分/合并、跨世界/对角不连通；重复Circuit只选一个入口，60kW全计入原电路负载/过载。部分付款不能因为Unpowered而丢掉，未付费工作量为0；2秒不足切备、5秒付费回切试验失败退回，空闲不误切。
8. **建筑交互**：电线/管道/轨道/自动化叠放、施工预览、完成、拖线、替换与安全拆除；普通门/普通砖/其他模组行为不受本mod补丁影响。
9. **UI布局**：1280×720、1920×1080、常用缩放；基础操作可达、详情最多一个展开、无嵌套争滚；人物权限原面板正常共存；普通储物箱/电池等原生菜单不被移动或隐藏。
10. **UI编辑**：中文IME/小数文化、负数/NaN/无穷/空文本、0与无限制；错误文本切换其他字段或重新选中仍保留；暂停或状态刷新不改变焦点；应用/撤销/排空只读/取消明确；外部复制标记草稿过期。
11. **选择与批量**：发现过滤、已选未发现/未知元素保留、分类/搜索/清空搜索/无结果、当前列表全选只影响当前过滤；关弹层/切目标/旧回调不写新建筑。网络预览后新增/删除/待修改节点按快照计数，方向跨轴保留且结果明确。
12. **性能与兼容**：500单元持续运行、日志无刷屏、长中文/英文及其他模组元素名、全DLC/基础内容、退出到菜单后新开世界，静态网络/预约不串档。

13. **原创外观与拼接**：砖16种邻接、横向/纵向阵列、砖门相邻、门两朝向、世界/行边界；触点形成完整节点，普通砖、施工预览不连接。建造完成/取消/拆除、熔化、退出菜单后重开都不残留连接；门自身两格之间不显示外部接点。
14. **膜与人物图层**：近看有细孔/层压纹、远看干净；暗/亮背景、气液、材质染色和选中高亮下有柔性半透明质感。膜不变成玻璃/发光护盾；角色通过时膜、人物、夹具层级正常；基础格不重复渲染普通砖。
15. **动画与状态**：关闭有中央细夹具、通行完整膜带、所有开闭帧无洞。连续两门、双人交错、临时锁门、快速反向、中断/死亡/消失、暂停读档以及后生成旅客，最终显示按实际旅客恢复。快速反向目前会从过渡端点重新播放，记录跳变程度以判断后续平滑需求。静止膜安静；实际主动输运才有小方向标，无电、暂停、待排空状态与侧栏一致；运行时灯刷新不重复重播门动画。
16. **0.1.2侧栏修复复测**：首次选膜砖/门、关闭后重选、被动→主动→被动、待配置/拆除按钮从隐藏恢复，均无空引用。元素弹层打开后改选普通建筑/切换侧栏页签/取消选中/销毁目标，弹层关闭、不能改旧建筑、草稿文本保留；搜索筛选后旧行不能误触，反复开关不残留绑定。输入搜索/目标上限/优先级时游戏快捷键被消费，中文IME正常；读档带Pending显示待值，自身排空完成不误报外部修改，外部Pending使未编辑/已编辑草稿都明确过期，显式重新载入待值且字段仍只读。

不以CLI测试输出、图层合成预览或编译成功代替这些实机记录。原创美术已编译接入，正式美术验收尚未执行。

17. **0.1.3常用交互**：首次选砖，主面板为状态/轴/介质/模式暂停/更多，说明深色可读，关闭更多无预留大空白。选氧气确认后Applied立即含氧气，不再二次应用；取消不改设置，暂停不被介质确认解除。模式与方向单击提交；有库存时显示Pending且禁用再次修改，旧路径排空，完成后按钮恢复。输入非法或未保存上限后切模式/改介质/暂停，原始文本保留且上限未误提交；保存上限不回退最新模式/介质。外部复制只改常用项可合并，改变上限时本地输入显示冲突；弹层打开后外部复制再确认会拒绝旧选择。切目标/页签/销毁的旧生命周期用例仍执行。
18. **0.1.3建造提示**：顶/底边旋转为上下，侧边左右；旋转键重绑定后说明显示新键。预览与选中砖均有轴与两侧框，正常青色、实体/计划砖橙色。拖建后相邻尚未完成的砖也计入阻挡，取消蓝图后警告恢复。原生建筑标题、材料余额、放置失败和快捷键说明仍存在。正常门1×2及旋转2×1各两个单元端点与实际位置一致。移开鼠标/换工具/取消选中/完成施工/拆除/切世界/退出后无残留图形。预览无配置为双向，已完成主动箭头匹配实际方向，Pending排空期间仍指旧方向；双向和青框不表示正在流动。
19. **截图场景复现**：外侧约1.252kg氧气、内部真空，单独配置顶边砖氧气。默认左右且邻居都是膜砖时显示阻挡，仍保持隔离；安全重建为上下轴后能缓慢输氧，核对源/目标/缓存总质量不变。内部若是其他元素或实体则明确说明阻塞；空白名单、已平衡、上限0、源变液体和外部泵/排口竞争均复测。仅选一砖不用给整圈配置；角砖不能凭“无阻挡”假定成功。
